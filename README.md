# Smart Money Management Bag - Landing Page

A premium, high-converting React, TypeScript, and Vite-powered landing page for the **Smart Money Management Bag** by **CanvasBag Bangladesh**.

## 🚀 Technologies Used
- **Frontend**: React 18 & TypeScript (compiled with Vite)
- **Styling**: Tailwind CSS & Framer Motion
- **Database**: Supabase
- **Analytics & Tracking**: 
  - Google Tag Manager (GTM)
  - Google Analytics 4 (GA4) Ecommerce Tracking
  - Meta Pixel (Facebook Pixel)
  - Facebook Conversions API (CAPI) with SHA-256 secure user data hashing

## ⚙️ Setup & Running Locally
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## 📦 Deployment
This project is configured for deployment on **Vercel** out of the box via the `vercel.json` file.
